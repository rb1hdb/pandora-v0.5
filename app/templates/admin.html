01 — Defenses ▾
D1 Input Filter
Deterministic pattern filtering — detects technical attacks in input (SQL injection, XSS, command injection), LLM control delimiters and credential exposure, including base64-obfuscated variants
D2 Input Judge
Semantic classification via LLM — analyzes user intent to detect prompt injection, instruction override attempts, data exfiltration and malicious behaviors not capturable by regex
D3 SP Lock
Rigid system prompt protection — injects priority security rules that prevent leaking of internal instructions, credentials and any override or manipulation attempt on model behavior
D4 SP Alignment
Behavioral and context restriction — reinforces model alignment by limiting scope, blocking roleplay, preventing indirect prompt injection (RAG poisoning) and avoiding manipulation via memory/conversation
D5 Output Judge
Semantic response validation — uses LLM to detect sensitive information leakage in output (PII, credentials, system prompt, infrastructure) and generate a safe version when needed
D6 Output Sanitizer
Deterministic output sanitization — applies multiple cleaning layers: HTML neutralization (anti-XSS), URL removal (anti-exfiltration), PII and credential masking, and detection of sensitive data hidden in base64
